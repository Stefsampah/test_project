# Roadmap prochaine session

Objectif: finaliser une V2 propre, cohérente, orientée conversion.

## 1) Correctifs bloquants UX
- Corriger l'affichage des formulaires d'authentification (texte blanc sur fond blanc).
- Vérifier les vues Devise: connexion, inscription, reset mot de passe.
- Confirmer lisibilité mobile/desktop sur tous les champs.

## 2) Cohérence UI globale
- Uniformiser tous les boutons de l'app (taille, rayon, couleurs, hover, disabled).
- Faire une passe visuelle sur: home, playlists, game, results, profile, journey, classement, VIP.
- Supprimer les incohérences de style restantes.

## 3) Homepage alignée au nouveau gameplay
- Recentrer le message sur le flow:
  playlists -> swipe -> points saison -> paliers concert.
- Un CTA principal "Jouer".
- Un CTA secondaire "Voir mon parcours".

## 4) Refonte page VIP (conversion)
- Clarifier la proposition de valeur (limite/jour, confort, avantages).
- Design plus premium et plus motivant.
- Réduire le texte, augmenter la clarté bénéfices + CTA.

## 5) Revue théorique gameplay/business
- Estimer le temps pour atteindre 3000 / 6000 points (free vs VIP).
- Vérifier si le volume de contenu actuel est suffisant.
- Ajuster si besoin:
  - points par swipe,
  - limite quotidienne,
  - cadence d'ajout de contenu.

## 6) QA final avant validation
- QA mobile complet FR + EN:
  playlists -> game -> results -> profile -> journey -> classement.
- Vérifier navigation, traductions, débordements, feedbacks swipe.
- Préparer checklist de sortie "V2 prête test utilisateur".
